# Security

This repository is a public case study and does not contain the AfterFive production source code.

Please do not use this repository to report generic issues with the public documentation.

If you believe you have identified a genuine security issue affecting the live AfterFive product, use the support/contact channel published on the live product rather than opening a public issue containing exploit details or sensitive information.

## Disclosure boundary

Production credentials, privileged configuration, internal authentication details, private schemas, deployment secrets, and proprietary source code are intentionally excluded from this repository.
