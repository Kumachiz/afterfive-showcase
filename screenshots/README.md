# Product Screenshots

This directory is reserved for curated screenshots of the live AfterFive product.

Only screenshots that are safe for public portfolio use should be added here. Do not include:

- admin credentials or authentication details
- private customer / organizer information
- tokens, environment variables, API keys, or debug output
- internal-only URLs or security-sensitive configuration
- private database or infrastructure details

The public case study works without screenshots, so this folder can be populated selectively as the product presentation evolves.
